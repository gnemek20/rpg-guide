# 간편조작
> 작물 수확, 나무 벌목과 찹트리, 레시피 북 자동제작, 장비 교체를 빠르게 익힙니다.

## 자주 쓰는 조작

아래 조작은 게임 안에서 사용합니다. Shift와 F는 기본 키 설정 기준입니다.

| 하고 싶은 일 | 조작 | 결과 |
|---|---|---|
| 상점 바로 열기 | 상인 마르코 또는 블록 상인 헤이즐 우클릭 | 대화 선택 없이 해당 상점을 엽니다 |
| 작물 한 번에 수확 | 소속 섬의 다 자란 작물 우클릭 | 이어진 밭의 다 자란 작물을 수확하고 다시 심습니다 |
| 나무 한 번에 벌목 | 도끼로 나무 밑동의 원목 파괴 | 이어진 같은 종류의 원목을 연쇄 벌목합니다 |
| 재료 배치 없이 제작 | 제작대의 레시피 북에서 조합법을 열고 결과물 클릭 | 인벤토리 재료를 사용해 1회 제작합니다 |
| 여러 번 제작 | 조합법 상세 화면의 결과물 Shift + 클릭 | 재료가 있는 만큼 최대 64회 제작합니다 |
| 레시피 찾기 | 레시피 북의 검색을 누르고 채팅에 아이템 이름 입력 | 해당 이름의 조합법을 찾습니다 |
| 장비 빠르게 착용 | `/장비`를 연 뒤 내 인벤토리의 장비 Shift + 클릭 | 자동 장착 설정이 켜져 있으면 맞는 칸에 장착합니다 |
| 장비 묶음 저장 | `/프리셋`에서 원하는 칸 우클릭 | 현재 장비를 그 칸에 저장합니다 |
| 저장한 장비로 교체 | `/프리셋`에서 저장한 칸 좌클릭 | 보유 중인 장비로 갈아입습니다 |
| 무기 마법 확인 | 마법이 각인된 무기를 들고 Shift + F | 클릭별로 지정된 마법을 채팅에 표시합니다 |
| 섬이나 마을로 이동 | `/섬`, `/spawn` 또는 `/넴주` | 소속 섬이나 마을로 바로 이동합니다 |

## 작물 일괄 수확

자신이 소유하거나 일원으로 참여한 섬에서 **다 자란 작물 하나를 우클릭**해 보세요. 이어진 밭의 다 자란 작물을 기본 **최대 512칸**까지 한 번에 수확합니다. 덜 자란 작물은 남겨 두고, 수확한 자리에서는 작물이 다시 자랍니다. 씨앗을 다시 배치할 필요가 없습니다.

- 기본 수확은 **빈손으로도 가능합니다.** 괭이를 들면 해당 도구의 잠재능력도 적용됩니다.
- 밀, 당근, 감자, 비트루트, 네더 사마귀, 코코아, 달콤한 열매와 같은 방식으로 자라는 약초가 대상입니다.
- 한 칸짜리 물길이나 통로를 사이에 둔 밭, 높이 차이가 한 칸인 밭도 이어서 찾습니다. 멀리 떨어진 밭은 따로 수확해 주세요.
- 수박과 호박 열매는 이 우클릭 일괄 수확의 대상이 아닙니다.
- 방문만 한 다른 사람의 섬에서는 사용할 수 없습니다.

작물과 묘목의 성장 조건은 [개인 섬 안내](/guide/island/)에서 확인할 수 있습니다.

## 나무 연쇄 벌목

**도끼로 나무 밑동의 원목을 캐면** 위쪽과 옆으로 이어진 같은 종류의 원목을 기본 **최대 512개**까지 한 번에 벱니다. 흔히 찹트리라고 부르는 기능입니다. 곡괭이나 빈손으로는 연쇄 벌목이 발동하지 않습니다.

벌목 경험치와 추가 재료는 **자연히 자란 나무**에서 얻습니다. 묘목을 심어 키운 나무도 해당하며, 직접 쌓은 원목이나 나뭇잎이 이미 사라진 나무는 경험치가 나오지 않을 수 있습니다.

같은 종류의 원목을 이어 지은 구조물도 함께 베어질 수 있으므로 건축물을 해체할 때는 도끼 사용에 유의해 주세요. 베고 난 자리의 묘목은 직접 다시 심습니다.

## 레시피 북 자동제작

웹의 제작 트리로 재료를 살펴본 뒤, 실제 제작은 **게임 안 제작대**에서 진행합니다.

1. 제작대를 우클릭해 **대장간**을 엽니다.
2. 오른쪽 위의 **레시피 북**을 누릅니다.
3. 원하는 아이템을 선택해 **조합법 상세**를 엽니다. 목록에서 클릭하는 것만으로는 제작되지 않습니다.
4. 해당 조합의 재료를 인벤토리에 준비하고 **오른쪽 결과물을 클릭**합니다. 재료를 제작 칸에 직접 배치하지 않아도 됩니다.

| 결과물 조작 | 제작 횟수 | 결과물을 받는 곳 |
|---|---|---|
| 일반 클릭 | 1회 | 마우스 커서 |
| Shift + 클릭 | 재료가 있는 만큼 최대 64회 | 인벤토리 |

**64회는 결과물 64개와 다를 수 있습니다.** 한 번에 4개를 만드는 조합이라면 64회 제작 시 최대 256개가 나옵니다. 대량 제작 중 인벤토리에 들어가지 않는 결과물은 **발밑에 떨어지므로**, 먼저 공간을 비워 주세요.

클릭해도 반응이 없다면 재료 종류와 수량을 확인하세요. 일반 클릭은 커서를 비우거나, 같은 결과물을 더 담을 공간이 있어야 합니다. 부족한 재료가 있을 때는 일부 재료만 먼저 소모하지 않습니다.

레시피 북 아래쪽의 **검색**으로 한글 아이템 이름을 찾고, **분류**로 전체, RPG 전용, 바닐라를 전환할 수 있습니다. 검색할 때는 `철곡괭이`처럼 띄어쓰기 없이 입력해도 됩니다.

필요 재료와 상위 조합은 [제작 트리](/tree/)에서 확인할 수 있습니다.

## 장비 교체와 마법 확인

`/장비`를 연 상태에서 내 인벤토리의 장비를 **Shift + 클릭**하면 자동 장착합니다. 반응이 없다면 설정의 **장비창 자동 장착**이 켜져 있는지 확인해 주세요.

`/프리셋`은 **우클릭으로 저장**, **좌클릭으로 장착**합니다. 이미 저장한 칸에 우클릭하면 현재 장비로 덮어씁니다. 저장 후에도 해당 장비를 보유해야 갈아입을 수 있습니다.

마법이 각인된 무기를 든 채 **Shift + F**를 누르면 좌클릭, 우클릭, Shift 조합에 지정된 마법이 표시됩니다. 자세한 내용은 [장비 안내](/guide/gear/)와 [마법 안내](/guide/magic/)를 참고해 주세요.

## 빠른 이동

- `/섬`: 소속 섬으로 이동합니다. 처음에는 섬을 생성하며, 참여 중인 섬이 있으면 그 섬이 우선입니다.
- `/spawn` 또는 `/넴주`: 골드나 귀환석을 쓰지 않고 마을로 돌아갑니다.
- `/섬 허브`: 섬 관리 화면을 엽니다. 이동 명령과 구분해 사용해 주세요.

튜토리얼 진행 중에는 완료하거나 건너뛴 뒤 이동할 수 있습니다. 섬 월드를 처음 준비할 때는 잠시 기다릴 수 있습니다.

# 경제
> 사고, 맡기고, 올리고, 주고받는 곳을 정리했습니다.

## 어디서 무엇을
| 곳 | 하는 일 |
|---|---|
| 상인 마르코 | 물건 사고팔기. 재료는 시세가 움직입니다 |
| 블록 상인 헤이즐 | 건축 블록 |
| 은행원 그레타 | 골드 맡기기, 송금. 맡긴 골드는 **죽어도 잃지 않습니다** |
| 경매인 루시안 | 정가로 올리고 사기. 대금은 우편으로 옵니다 |
| 우체부 코넬 | 우편함. 보상, 송금, 경매 대금을 받습니다 |
| `/거래` | 플레이어끼리 직접 거래 |

수수료, 이자, 상점 가격은 [경제](/economy/)에 있습니다.

## 알아 둘 것
- 다이아몬드 같은 일부 품목은 하루 판매 한도가 있습니다.
- 강화, 잠재능력이 붙은 아이템은 **귀중품 보호**로 실수로 팔리지 않습니다. 환경 설정에서 끌 수 있습니다.
- 상점 판매 때 확인 창이 뜨고, 판 물건은 되살 수 있습니다.

# [공지] 버그 등급 분류 기준 안내

안녕하세요.

서버 내 버그의 중요도와 수정 우선순위를 명확하게 관리하기 위해 **버그 등급 분류 기준**을 적용합니다.

버그 등급은 **피해 심각성(1~4)**&#xACFC; **재현성(A~D)**&#xC744; 조합하여 총 16단계로 분류됩니다.

---

## 1. 피해 심각성

숫자가 **낮을수록 심각한 버그**입니다.

| 등급    | 기준                             |
| ----- | ------------------------------ |
| **1** | 데이터 손실, 경제 붕괴, 서버 다운 등 치명적인 피해 |
| **2** | 핵심 게임플레이 또는 콘텐츠에 상당한 피해        |
| **3** | 플레이에 불편이나 이상이 있으나 큰 피해는 없는 경우  |
| **4** | 실질적인 피해가 거의 없는 사소한 오류          |

---

## 2. 재현성

알파벳이 **A에 가까울수록 동일한 조건에서 재현하기 쉬운 버그**입니다.

동일한 조건에서 반복 테스트했을 때의 발생 횟수를 기준으로 판단합니다.

| 등급    | 기준                                     |
| ----- | -------------------------------------- |
| **A** | 동일 조건에서 10회 중 10회 발생                   |
| **B** | 동일 조건에서 10회 중 7~9회 발생                  |
| **C** | 동일 조건에서 10회 중 2~6회 발생                  |
| **D** | 동일 조건에서 10회 중 0~1회 발생 또는 재현 조건 확인이 어려움 |

---

## 3. 버그 등급표

| 피해 심각성 / 재현성 | **A**  | **B**  | **C**  | **D**  |
| ------------ | ------ | ------ | ------ | ------ |
| **1 (치명적)**  | **1A** | **1B** | **1C** | **1D** |
| **2 (높음)**   | **2A** | **2B** | **2C** | **2D** |
| **3 (낮음)**   | **3A** | **3B** | **3C** | **3D** |
| **4 (무해)**   | **4A** | **4B** | **4C** | **4D** |

**1A가 가장 높은 등급이며, 4D가 가장 낮은 등급입니다.**

---

## 4. 등급 적용

버그의 최종 등급은 **실제 피해 정도와 재현성**을 기준으로 판단합니다.

재현성은 가능한 경우 동일한 조건에서 반복 테스트하여 객관적으로 평가합니다.

또한 서버 안정성, 데이터 보존, 경제 시스템 등 운영에 중대한 영향을 미치는 버그는 등급과 관계없이 **긴급 대응**될 수 있습니다.

감사합니다.
